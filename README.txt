SOLANIS TRANSPORT WEBSITE
=========================

FILES
-----
index.html      Main website
styles.css      All design and responsive styling
script.js       Mobile menu, sticky header, animations
assets/         Logo and website images

UPLOAD TO GITHUB
----------------
1. Unzip this folder.
2. Upload everything INSIDE the folder to the root of your GitHub repository.
3. Replace the old index.html, styles.css, script.js, and assets folder.
4. Commit the changes.
5. GitHub Pages may take 1–3 minutes to refresh.
